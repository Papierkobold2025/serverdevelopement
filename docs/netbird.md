# Netbird Service Integration

- Instalación de Netbird para reemplazar a Wireguard con una aplicación administrada por panel

## Decisiones

- Reemplazar el puerto de Nextcloud Talk 3478 por Netbird por configuración estandar de paquete de instalación

- Reemplazar el puerto 8081 para conexiones por el puerto 80 por ser el puerto donde el host del docker escucha

- Edición de parámetros de red a nivel de servidor ``` bash network_mode: host ``` para aceptar trafico de red que recibe el contenedor

- IP de pihole agregada a configuración como trustedHTTPProxies para permitir la resolución de nombres DNS

- Separación de Realms para administración y acceso de usuarios

- Instalación de Quick Install, para evitar la configuración de cuatro dockers distintos

### Dificultades encontradas

- Peer no podía hablar con peer en LAN por configuración de Netbird: lazy connection, en donde si no existe trafico de red entre los dos peers no se establece handshake

    - Solución ping a peer en LAN activó inmediatamente la conexión

### Runbook

- Script de instalación de Netbird

    - ``` bash curl -fsSL https://github.com/netbirdio/netbird/releases/latest/download/getting-started.sh | bash ```

- ~/docker-compose.yml

``` bash
services:
  # UI dashboard
  dashboard:
    image: netbirdio/dashboard:latest
    container_name: netbird-dashboard
    restart: unless-stopped
    networks: [netbird]
    ports:
      - '0.0.0.0:8080:80'
    env_file:
      - ./dashboard.env
    logging:
      driver: "json-file"
      options:
        max-size: "500m"
        max-file: "2"
  # Combined server (Management + Signal + Relay + STUN)
  netbird-server:
    image: netbirdio/netbird-server:latest
    container_name: netbird-server
    restart: unless-stopped
    network_mode: host
    cap_add:
      - NET_ADMIN
    volumes:
      - netbird_data:/var/lib/netbird
      - ./config.yaml:/etc/netbird/config.yaml
    command: ["--config", "/etc/netbird/config.yaml"]
    logging:
      driver: "json-file"
      options:
        max-size: "500m"
        max-file: "2"
volumes:
  netbird_data:
networks:
  netbird:
```

- ~/config.yaml

``` bash
# Combined NetBird Server Configuration (Simplified)
# Generated by getting-started.sh

server:
  listenAddress: ":80"
  exposedAddress: "https://netbird.network.mydomain.com:443"
  stunPorts:
    - 3478
  metricsPort: 9090
  healthcheckAddress: ":9000"
  logLevel: "info"
  logFile: "console"

  authSecret: "authSecret"
  dataDir: "/var/lib/netbird"

  auth:
    issuer: "https://netbird.network.mydomain.com/oauth2"
    signKeyRefreshEnabled: true
    dashboardRedirectURIs:
      - "https://netbird.network.mydomain.com/nb-auth"
      - "https://netbird.network.mydomain.com/nb-silent-auth"
    cliRedirectURIs:
      - "http://localhost:53000/"

  reverseProxy:
    trustedHTTPProxies:
      - "192.168.X.X/32"

  store:
    engine: "sqlite"
    encryptionKey: "encryptionKey"
```

- Configuración dentro de NGINX para que los peers funcionen correctamente

``` bash
client_header_timeout 1d;
client_body_timeout 1d;

location ~ ^/(relay|ws-proxy/) {
    proxy_pass http://192.168.X.X:80;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_read_timeout 1d;
}

location ~ ^/(signalexchange\.SignalExchange|management\.ManagementService)/ {
    grpc_pass grpc://192.168.X.X:80;
    grpc_read_timeout 1d;
    grpc_send_timeout 1d;
    grpc_socket_keepalive on;
}

location ~ ^/(api|oauth2)/ {
    proxy_pass http://192.168.X.X:80;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

- Al terminar configuraciones se tiene que ajustar todavia la red dentro de Netbird mismo para enmascarar tráfico y crear rutas de acceso de red mediante peers
